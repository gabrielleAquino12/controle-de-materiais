# Controle de Materiais

## Sobre o projeto
Sistema desenvolvido como MVP para auxiliar no controle de materiais e movimentação de estoque.

## Objetivo
Facilitar o cadastro, a consulta e o acompanhamento dos materiais.

## Funcionalidades
- Cadastro de materiais.
- Consulta de estoque.
- Registro de movimentações.
- Painel informativo.

## Objetivo de Desenvolvimento Sustentável
ODS 12 – Consumo e Produção Responsáveis.

## Acessibilidade
O sistema busca oferecer textos legíveis, bom contraste e botões identificáveis.# controle-de-materiais
Sistema MVP para controle de materiais e movimentação de estoque
## Funcionalidades do sistema

- Cadastro de materiais e categorias.
- Consulta e pesquisa do estoque.
- Registro de entradas e saídas.
- Controle de quantidade mínima.
- Alertas de estoque baixo.
- Histórico de movimentações.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Armazenamento

Os dados são armazenados no navegador por meio do LocalStorage.

## Objetivo do projeto

Contribuir para o consumo e a produção responsáveis, conforme a ODS 12, por meio do controle de materiais, evitando desperdícios e facilitando o acompanhamento do estoque.

## Público-alvo

Pequenas instituições e organizações que precisam controlar seus materiais.
